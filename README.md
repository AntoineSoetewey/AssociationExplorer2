# AssociationExplorer2

New version of the AssociationExplorer R Shiny app (see https://github.com/AntoineSoetewey/AssociationExplorer), which implements the following changes:

- [x] Ranges instead of cutoffs for strength associations (https://github.com/AntoineSoetewey/AssociationExplorer2/commit/ed89fc139b4d3c2e818a25a7a98c9d48b720f386)
- [x] Survey weights (https://github.com/AntoineSoetewey/AssociationExplorer2/commit/72725331a2b461f534355eb4b65051e088efb471)
- [ ] Option to flip the X and Y axes in quantitative-quantitative pairs plots
